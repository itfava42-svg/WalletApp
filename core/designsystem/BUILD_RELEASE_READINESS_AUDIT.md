# CI-192 — ممیزی نهایی آماده‌سازی Build/Release

## دامنه
این مرحله فقط ممیزی خواندنی تنظیمات Gradle، ماژول‌ها و Manifest است. هیچ تنظیم runtime، مجوز، پشتیبان‌گیری یا امضای انتشار بدون تصمیم صریح و آزمون سازگاری تغییر داده نشد.

## یافته‌های تأییدشده
- پروژه شامل ماژول‌های `:app` و `:core:designsystem` است؛ ماژول app به DesignSystem وابسته است و وابستگی معکوس در فایل‌های بررسی‌شده دیده نشد.
- هر دو ماژول از Android Gradle Plugin نسخه 8.5.2 و Kotlin Android plugin نسخه 1.9.24 استفاده می‌کنند.
- Wrapper روی Gradle 9.5.0 تنظیم شده و `distributionSha256Sum` و `validateDistributionUrl=true` دارد.
- تنظیمات برنامه: `compileSdk=34`، `minSdk=24`، `targetSdk=34`، `versionCode=1`، `versionName=1.0`.
- نوع build انتشار در حال حاضر `isMinifyEnabled=false` دارد؛ بنابراین کوچک‌سازی/obfuscation برای release فعال نیست.
- Manifest شامل مجوزهای SMS، دوربین، اعلان‌ها، exact alarm، اینترنت و overlay است. این ممیزی مجوزها را حذف یا تغییر نمی‌دهد چون می‌تواند قابلیت‌های واقعی برنامه را مختل کند.
- `android:allowBackup=true` فعال است؛ تغییر آن نیازمند تصمیم محصولی درباره بازیابی داده‌های کیف پول است.
- فعالیت launcher دارای `android:exported=true` است؛ receiver پیامک نیز exported است تا پیام‌های سیستمی SMS دریافت شوند. این نقاط باید در بررسی امنیت انتشار جداگانه اعتبارسنجی شوند.
- فایل workflow با مسیر حدسی `.github/workflows/android-ci.yml` در این شاخه وجود نداشت؛ از این نتیجه‌گیری نمی‌شود که workflow وجود ندارد، فقط نام/مسیر واقعی آن از این بررسی تأیید نشد.
- در این مرحله فایل امضای release یا تنظیمات کلید امضا بررسی/تغییر داده نشد؛ کلیدها و اسرار نباید در مخزن قرار گیرند.

## تصمیم
CI-192 یک ممیزی مستنداتی است و هیچ تغییر تولیدی لازم‌الاجرا را اثبات نکرد. به همین دلیل تغییرات خطرناک یا حدسی در تنظیمات release انجام نشد. قبل از انتشار واقعی باید سیاست امضا، افزایش versionCode، سیاست backup و بازبینی مجوزها به‌صورت مرحله‌ای و با تست مشخص شود.

## مرحله بعد
CI-193 — ممیزی امنیتی Manifest و مجوزهای حساس پیش از انتشار، بدون تغییر رفتاری تا زمان ثبت اثر هر مجوز و تأیید سازگاری.
